# PRODUCT — Interaction Lab（交互标本馆）

## 是什么

一个**开源的交互设计标本馆**：把交互设计中真正决定质感的细节——压缩比、缓动曲线、状态切换、让位逻辑——从「看过视频」变成**可上手操作、可被 AI 精确检索**的单文件组件。

- 48 个标本，6 大交互意图分类。
- 每个标本是一份零外部依赖的单文件 HTML，参数经过测量并以 Token 形式显式声明。
- 索引页是入口：直接操作标本，再进入对应的规范。

## 受众与场景

- **设计/前端从业者**：在桌面浏览器上逐个把玩，对照规范理解「为什么这样动」。
- **AI 编码 Agent**：通过 `ilab` CLI 或 `/patterns/{id}.md` 取回 Token 契约、状态机、反模式禁区与代码骨架，避免产出 `transition: all .5s ease` 这类无质感实现。

不是营销落地页，也不是后台工具——是 **Experience（体验/展陈）**：标本领先，界面退后。

## 产品真相（不可改）

六集交互世界的核心原则（各集页底附参数附录）：

| 世界 | 原则 |
| :--- | :--- |
| EP26 入口与反馈 | 选中 = 整块底色反转胶囊 + 小圆点，右侧内容同步切换 |
| EP27 新拟态 | 不画描边，一束左上光；外凸负责被看见，内凹槽接住动作 |
| EP28 动作回执 | 按钮先压下才承认被按，数字滚过才承认变了 |
| EP29 主角优先 | 先定谁当主角；栏数 / 卡片比例 / 字号阶梯跟着主角走 |
| EP30 硬边玻璃 | 毛玻璃需要硬边对比：硬边底 → 玻璃大卡 → 卡内玻璃条；拖 → 让位 → 吸附 |
| EP31 当前唯一 | 只点亮一个，其余退场（让位=位移 / 距离=透视） |

以及 16 个动效标本（Animation Lab）与它们的缓动/时序参数。

## 不变量

- **零外部依赖**：构建、服务、前端、CLI 全部只用标准库 / 原生 Web API；标本页零外部请求。
- **单文件标本**：每个标本可单独下载、单独嵌入、单独运行。
- **参数必须测量**：Token 与状态机的数值来自真实观察，不凭印象填写。
- **规范与实现同源**：`data/patterns.json` 同时驱动界面、API 与 `.md` 规范，不允许两处手写。
- **桌面优先**：按 Mac / 桌面浏览器验收；无障碍要求为真实控件、键盘可达、`focus-visible`、`prefers-reduced-motion`。

## 边界

- 不做移动端适配（见 `AGENTS.md`）。
- 不改动六个标本世界的内部演示与参数附录；共享部分只有页首顶栏（`src/chrome.css`）。
- 不收集明文 IP 或任何账号信息（见 README「遥测与隐私」）。

## 出处

交互思想与关键参数来自公开教学视频：抖音 @叨叨AI（EP26–31，6 个界面方向）与 @大锤师傅（16 个动效）。全部实现为本项目独立重写，未复制原始素材。
